Half of it comes back

Online fashion retailers like Zalando say about half of the items customers order are sent back. I analysed 2.3 million order lines from a German online fashion shop to find what drives returns, built a model that predicts them at checkout, and priced what cutting them is worth.

Independent analysis by Stephen tAMBI on public competition data. Not affiliated with Zalando or any retailer.

How it was built

  • Data:
  • Drivers: return rate = items returned ÷ items ordered, split by order features. "Two sizes" means the same article and colour ordered in more than one size in the same order.
  • Model: gradient boosting (scikit-learn) on price, discount, size and colour bracketing, basket size, payment type, device, product group, voucher and the customer's own earlier return rate. Trained on Jan 2014 to Mar 2015, tested on Apr to Sep 2015.
  • Money: savings count only the handling cost of each avoided return. Lost margin, shipping out and the carbon cost are left out, so the real value is higher. The two levers partly overlap, so their sum is an upper estimate.
Data: Data Mining Cup 2016 by prudsys AG, order data of a German online fashion retailer (the retailer is not named). Zalando return figures: Zalando corporate website ("Returns at Zalando") and its April 2025 return policy update. Return cost range: University of Bamberg, Research Group Returns Management (2022).
