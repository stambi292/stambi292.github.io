Analytics Enablement Kit

Before a dashboard helps anyone decide, its numbers have to reconcile, its KPIs need one definition, users need to know how to read it, and AI tools need answers they can be checked against. This kit does all four on one real example: a global beauty company's FY25 net revenue.

    Step 3 · Dashboard enablementA dashboard a new user can read in a minute

    Onboarding: read it in 60 seconds

    1. Start with the total. $5.9bn, down 4% reported but only 2% like-for-like: currency and portfolio changes explain about half the fall.
    2. Switch to Region. EMEA is the only region that grew (+1%), and it is the largest.
    3. Switch to Segment. Consumer Beauty shrank 8%; Prestige held almost flat.
    4. Read the margin. Prestige earns 20 cents per dollar, Consumer Beauty 4: the profit sits in Prestige.

    Knowledge base

    Why does reported growth differ from LFL?

    Reported growth includes currency moves and portfolio changes. LFL strips them out, so use LFL to judge a market's real performance.

    Why do region and segment views give the same total?

    They slice the same net revenue two ways. If they ever differ, the data quality log flags it before the dashboard refreshes.

    Who do I ask about a number?

    The KPI's source owner in the data dictionary; analytics escalates data issues, finance owns adjusted definitions.

    Step 4 · AI adoptionA prompt library with answers you can check
